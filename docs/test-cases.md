 # AI Video Copilot 测试记录

## 测试目标

验证 AI Video Copilot 在不同用户输入情况下，是否能够：

- 正确识别视频需求
- 检查必填参数
- 参数完整时进入脚本生成流程
- 参数缺失时主动追问
- 工具调用失败时返回可理解的错误信息

## 通过标准

满足以下条件视为 Demo 基本通过：

1. 参数完整时能够正常进入 Workflow
2. 缺少必填参数时不会直接调用 Tool
3. 已知参数不会重复询问
4. Tool 成功时能够返回脚本
5. Tool 失败时能够返回明确错误信息
6. UI / Agent 最终反馈能够让普通用户理解

AI Video Copilot 当前重点验证：
